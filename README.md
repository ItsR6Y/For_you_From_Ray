# For You Website

A dramatic, chaotic, emotionally dangerous love letter disguised as a website.

## Setup for GitHub Pages

1. Upload all files to your GitHub repo
2. Enable GitHub Pages (Settings → Pages → Branch: main)
3. That's literally it 💀

## Add Your Audio Files

Drop these into the `/assets/` folder:
- `intro.mp3` — background music for the opening
- `sad.mp3` — emotional violin/rain vibes (page 2)
- `sus.mp3` — bass boosted chaotic (page 5 twist)
- `celebration.mp3` — party / victory music (page 6)
- `lie.mp3` — dramatic sound for lying (page 3)
- `meow.mp3` — cat meow for easter eggs

Audio is optional — the site works without it, just with less emotional damage.

## Add Your Images

In the code, look for image placeholders:
- `.sad-image-placeholder` → replace with `<img src="assets/you-sad.jpg">` 
- `.big-image-placeholder` → replace with `<img src="assets/portrait.jpg">`

## Easter Eggs

- Triple click anywhere → floating bats appear 🦇
- Konami code (↑↑↓↓←→←→BA) → full chaos mode
- Random "EMOTIONAL DAMAGE" flashes
- Fake error messages
- The "yes" button is uncatchable (by design)
